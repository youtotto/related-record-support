# 関連レコードサポート

標準の操作を変えず、親子の関連レコードを見つけやすく、確認しやすくするkintoneプラグインです。

[無料版 2.0.0 をダウンロード](https://github.com/youtotto/related-record-support/releases/tag/v2.0.0)

[機能紹介・製品版・試用版](https://www.nestrec.com/related-record-support)

## 無料版

- 親の名前と値を共通の列で表示
- 親ごとの子レコード件数とネスト表示
- 全件展開・折りたたみ・再読み込み
- 親・子の標準レコード詳細へのリンク

無料版には利用期限がありません。レコードの追加・編集・保存はkintone標準画面を使います。

## 関連レコードサポート＋

表示内検索、条件絞り込み、条件付き強調表示、任意の表示専用小計を追加します。集計値の書き戻し、グラフ・画像保存は行いません。

価格は税込11,000円・買い切り（1製品・1ドメイン）。試用は申込みから1か月間、自動課金なし。アップデート・通常サポートの追加費用はありません。

## 導入

配布用の `related-record-support-2.0.0-free-bundle.zip` を展開し、同梱の `related-record-support-2.0.0-free-plugin.zip` を解凍せずkintoneシステム管理のプラグインへ読み込みます。詳しくは同梱の導入ガイドをご覧ください。

旧「関連レコード - ネスト表示」と同じプラグインIDです。無料・＋・試用の切り替えは同一ドメインの利用アプリ全体へ適用されます。アンインストールせず更新してください。

## 対応範囲

PC版の詳細画面向けです。表示・検索・集計は利用者が閲覧でき、取得済みの関連レコードの範囲です。元データ変更後は再読み込みしてください。

このリポジトリは無料版の配布用です。開発ソース・署名鍵・有料版は含めません。
